# MASTER PROMPT — H MOOD
## AI-Powered Desktop Music Experience

Agis comme une équipe experte composée d'un développeur Java senior, d'un architecte logiciel, d'un designer UI/UX premium et d'un spécialiste de l'intelligence artificielle musicale.

Ta mission est de concevoir et développer **H MOOD**, une application musicale de bureau pour PC, moderne, intelligente, élégante et immersive.

H MOOD n'est pas un simple lecteur de musique. C'est un véritable compagnon musical intelligent qui comprend les émotions, les goûts et les habitudes de l'utilisateur afin de lui proposer la musique qui correspond parfaitement à son humeur et à chaque moment de sa journée.

---

# 1. IDENTITÉ DE LA MARQUE

**Nom :** H MOOD  
**Slogan :** Feel Your Mood. Live Your Music.

**Positionnement :**
H MOOD est une plateforme musicale desktop qui combine musique, intelligence artificielle, émotions, personnalisation et expérience utilisateur premium.

**Personnalité de la marque :**
- Futuriste
- Élégante
- Intelligente
- Émotionnelle
- Minimaliste
- Premium
- Dynamique

Créer un logo moderne autour de la lettre H et d'un symbole évoquant les ondes sonores, la musique ou les émotions.

L'identité visuelle doit être reconnaissable, cohérente et professionnelle.

# 2. TECHNOLOGIES OBLIGATOIRES

L'application doit être développée pour ordinateur Windows, avec une architecture évolutive.

Stack technique recommandé :
- Java 21
- JavaFX 21 pour l'interface graphique
- FXML pour structurer les interfaces
- CSS pour le design
- Maven pour la gestion du projet
- SQLite pour le stockage local
- JavaFX Media pour la lecture audio
- Java Sound API pour certaines fonctionnalités audio complémentaires

Prévoir une architecture permettant d'intégrer ultérieurement :
- Une API d'intelligence artificielle
- Des services de recommandation musicale
- Des catalogues musicaux externes disposant des autorisations nécessaires
- Un backend Spring Boot si le projet évolue

Le projet doit être modulaire, propre, maintenable et documenté.

# 4. STRUCTURE PRINCIPALE DE L'APPLICATION

Créer une fenêtre principale organisée en quatre zones :

## A. Sidebar gauche

Afficher :
- Logo H MOOD
- Home
- Discover
- My Music
- Playlists
- Mood Scanner
- AI DJ
- Music DNA
- Time Machine
- Focus Mode
- Sleep Mode
- Settings

La sidebar doit être élégante, compacte et intuitive.

## B. Zone centrale

Elle affiche le contenu de la page sélectionnée.

## C. Panneau intelligent à droite

Créer un panneau AI Assistant capable d'afficher :
- Des recommandations personnalisées
- Des suggestions selon l'humeur
- Des playlists générées
- Des conseils musicaux
- Des interactions conversationnelles

## D. Barre de lecture inférieure

Afficher :
- Pochette de l'album
- Titre

- Bouton suivant
- Barre de progression
- Volume
- Mode aléatoire
- Répétition
- File d'attente

La barre doit rester visible dans toute l'application.

# 5. DASHBOARD — HOME

Créer un tableau de bord personnalisé avec :

- Message de bienvenue
- Humeur actuelle
- Recommandations du jour
- Musiques récemment écoutées
- Playlists personnalisées
- Tendances musicales
- Suggestions de l'AI DJ
- Statistiques d'écoute

Ajouter une section :

**YOUR MOOD TODAY**

Elle affiche l'humeur détectée ou sélectionnée par l'utilisateur, accompagnée d'une playlist adaptée.

# 6. MOOD SCANNER — LE CŒUR DE H MOOD

Créer une fonctionnalité centrale permettant à l'utilisateur d'indiquer son état émotionnel.

Humeurs disponibles :
- Happy
- Sad
- Romantic
- Energetic
- Relaxed
- Angry
- Motivated
- Nostalgic
- Focused
- Lonely
- Confident
- Dreamy

L'utilisateur doit pouvoir sélectionner son humeur manuellement.

Prévoir également un questionnaire intelligent facultatif permettant d'affiner la recommandation.

L'application doit ensuite proposer :
- Une playlist adaptée
- Des artistes recommandés
- Des morceaux similaires
- Une ambiance visuelle correspondante
- Une durée d'écoute suggérée

Ne pas prétendre détecter automatiquement les émotions à partir de la caméra ou du microphone sans consentement explicite.

# 7. AI DJ — TON DJ PERSONNEL

Créer un DJ intelligent qui comprend les préférences musicales de l'utilisateur.

Fonctionnalités :
- Générer des playlists automatiquement
- Enchaîner les morceaux selon leur ambiance
- Adapter les recommandations à l'humeur
- Découvrir de nouveaux artistes
- Proposer des transitions musicales
- Créer des sessions d'écoute thématiques

Exemples de commandes :
- Play something for a rainy day.
- I need motivation.
- Give me a romantic playlist.
- Play music to help me concentrate.
- Surprise me with something new.

Prévoir une intégration IA via une API externe, avec une architecture permettant de changer de fournisseur.

# 8. MUSIC DNA — MON IDENTITÉ MUSICALE

Créer un espace qui analyse les habitudes d'écoute de l'utilisateur.

Afficher :
- Genres préférés
- Artistes favoris
- Morceaux les plus écoutés
- Ambiances dominantes
- Évolution des goûts
- Temps total d'écoute
- Découvertes musicales

Présenter les données avec des graphiques modernes.

Créer un profil musical évolutif appelé **MY MUSIC DNA**.

# 9. TIME MACHINE — VOYAGE MUSICAL

Créer une fonctionnalité permettant de retrouver les ambiances musicales d'une époque.

Exemples :
- 80s Vibes
- 90s Nostalgia
- 2000s Hits
- 2010s Memories
- Today's Sound

Permettre de filtrer les recommandations par décennie, genre et ambiance.
